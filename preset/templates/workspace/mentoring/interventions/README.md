# mentoring/interventions/ — 教学干预

命名 `YYYY-MM-DD-slug.md`。只有一项策略选择可能改变未来怎样教学时才值得写。

```markdown
---
type: intervention
lifecycle: active           # active | archived
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
intervention:               # 导师做了什么（改变挑战方向 / 换策略 / 停止某路线）
hypothesis_ref: null        # 该干预预期验证的 Hypothesis 相对路径；无则 null
rationale:                  # 为什么此刻选择该策略
outcome:                    # 实际效果（可观察）
future_decision_value:      # 为什么未来仍值得参考
frozen: false
archived_at: null
---

# <标题>
```

不得声称能力状态变化；Intervention 不是 Evidence。
