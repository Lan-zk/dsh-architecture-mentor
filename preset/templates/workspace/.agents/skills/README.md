# 技能覆盖层

把要定制的预设技能复制到 `<workspace>/.agents/skills/<同名技能>/` 再修改。
本目录技能 rank 200，会遮蔽预设内置同名技能（rank 300）。

- 复制后的副本**归你所有**：随你修改，不再随预设升级。
- 预设升级时，导师会提示你对覆盖副本做 diff 比对，手工决定是否跟进上游修复。
- `mentor-workspace-init` 永不复制到这里——它负责所有工作区的初始化与升级，
  必须始终取预设内置版本；不要在本目录创建同名技能。
- 新增自己的技能：直接在本目录创建 `<name>/SKILL.md`（name 必须 kebab-case）。
