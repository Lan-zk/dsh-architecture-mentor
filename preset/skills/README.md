# preset/skills/ — 随预设分发的导师技能

`customSkillDirs` 指向本目录，安装后随预设可见并随预设升级。共 6 个技能：

- `mentor-workspace-init`：初始化/升级工作区。
- `architecture-investigation`：调查陌生系统并重建架构事实。
- `architecture-challenge`：用挑战暴露学习者判断。
- `architecture-retrospective`：把决策、预测与结果连起来复盘。
- `learner-model-calibration`：维护长期记忆并校准学习者模型（含 Memory Curation 职责）。
- `mentoring-contract-management`：管理导师契约及其变更。

每个技能目录的 `SKILL.md` 是主文档。
