# 散文标准示例

用这些示例识别治理原则，不作为文本模板。"平衡" = 用最少解释保留每个有负载的命题。

## 保留每个事实子句

**原句：** "协调器按会话串行化写入，在 disposal 解析前冲刷缓冲事件，并向调用方报告后端失败。"

**过度裁剪：** "协调器串行化持久化。"

**平衡：** "协调器按会话串行化写入，在 disposal 解析前冲刷缓冲事件，并向调用方报告后端失败。"

删除装饰与重复，不删命题；actor、按会话作用域、disposal 顺序、失败可见性各自是独立事实。

## 显式技能范围是有功能的

**过度裁剪：** "读资料并使用判断。"

**平衡：** "本技能是 guidance，不是完整检查清单。除命名检查外仍要判断；文档化要求仍然适用。"

保留显式限制，因为它改变 agent 如何应用工作流；修剪重复说服，不修剪护栏。

## Cookbook 保留动作与验证

**过度裁剪：** "为工具加测试。"

**平衡：** "在单元层测试注册与 disposal，通过真实 loader 路径运行工具，输出变化时加快照。验证断言观察外部结果而非模型报告。"

保留测试分层、必需动作、真实入口与可观察验证；删除 fixture 叙述。

## 保留归属与时序

**过度裁剪：** "teardown 期间取消 provider 工作。"

**平衡：** "运行时在释放子 scope 前请求 provider 取消；provider 负责在 disposal 解析前 join 其 worker。"

actor、顺序、归属变化点与完成保证是独立事实子句。

## 事件 JSDoc 保留边界时序

**过度裁剪：** "组合并缓存会话前缀。"

**平衡：** "在第一步 pre-step 与模型请求前一次性组合会话前缀；listener append 加入当前请求，pre-step 压力计入接收组合后的前缀。"

事件顺序与对当前请求的后果是调用方可观察行为，不是实现叙述。

## 定向复杂代码而不叙述

**过度裁剪：** "Worker realm 支持。"

**平衡：** "拥有 worker realm 及其 host bridge。realm 初始化是 single-shot；disposal 终止 worker 并拒绝后续调用。协议理由见对应 Agent Note。"

保留模块角色、职责与非显然生命周期；用链接给理由，让代码展示局部控制流。

## 公开 JSDoc 包含失败

**过度裁剪：** "返回 realm 全局。"

**平衡：** "返回已初始化的 realm 全局。初始化未完成或已 disposed 时抛出。"

抛出与状态前置条件是调用方可观察的契约事实。

## 保留简洁的实现映射

**过度裁剪：** "由外部 API 支撑的搜索 provider。"

**平衡：** "把每个 provider 结果映射到共享搜索字段，保留标题、URL 与文本，省略 provider 专属排序元数据。"

保留解释适配器在哪里丢弃或改变信息的映射细节。

## 链接理由同时保留本地契约

**过度裁剪：** "Disposal 见对应 Agent Note。"

**平衡：** "Disposal 中止 run 并等待 provider 静止。归属与竞态处理见对应 Agent Note。"

在调用方需要处保留行为与完成保证；算法与理由激进链接。

## Implemented Agent Note 保留验证契约

**过度裁剪：** 因为已 shipped 就删除整个 Testing 节。

**平衡：** "单元测试覆盖取消在发布前后、disposal 静止与 provider reload。内置入口冒烟覆盖真实 loader 路径；快照覆盖因传输进程特定而延后。"

移除迁移任务与测试叙述；保留分层、它们钉住的行为、真实入口与命名缺口。

## 安全边界可能需要一个具体例子

**过度裁剪：** "挂载的插件共享 host 权限。"

**平衡：** "挂载的插件共享 host 权限；例如访问 `ctx.shell` 可执行 host executor 权限下的命令。"

当一个抽象安全限制需要操作上清晰时，保留一个例子。

## 删除推理转录

**过度详细：** "循环先检查值是否缺失。若缺失，下一分支提前返回。否则继续，所以最终断言安全。"

**平衡：** 当代码已表达这些分支时不写注释；若提前返回保护非显然不变量，只陈述该不变量。

不要压缩推理转录；删除它。

## 配置注释解释树无法表达的

**过度详细：** "该条目加载本地文件系统 provider，随后是策略插件，随后是读写编辑工具"，而相邻条目已显示该顺序。

**平衡：** "在模型面向工具前加载策略，使 write/edit 调用通过读前变更门禁。"

保留顺序的后果、令人惊讶的作用域规则或安全边界；让配置展示自己的清单。

## 不为词数裁剪

**当前：** "适配器把 provider 错误转换为共享错误类型，使调用方能统一处理认证、限流与瞬时失败。"

**更短但更差：** "适配器规范化 provider 错误。"

除非周边契约已列出失败类别，否则保留原句；更短版本丢失区分与后果。

## 模型可见文本遵循归属

**过度裁剪：** "工具在调用失败时返回错误。"

**过度详细：** 把另一个包的全部 schema 与渲染字符串复制进本 README。

**平衡：** 引用本包拥有的稳定 prompt/result/error 文本；schema 链接生成目录，其他包拥有的文本链接消费者 README，本地只陈述本包条件或差异。

## 生成摘要必须独立成立

**过度裁剪：** "审批请求与策略服务。"（随后 owner 才解释策略顺序与审计日志）

**过度详细：** 把服务完整生命周期与 prompt-notice 行为移入生成句。

**平衡：** "应用会话策略后再回答、并记录每次 ask/outcome 对到请求会话的审批服务。"

知道生成器提取什么；该片段必须在其生成的输出上保留契约。

## 限制是契约，不是债务清单

**过度裁剪：** 省略使配置变更需要插件重载的进程生命周期缓存。

**过度详细：** 列出私有 helper 清理与无调用方的测试访问器。

**平衡：** "Provider 选择在插件生命周期内缓存；安装或修复 provider 需要重载。"

保留影响使用或安全维护的缺口与非显然约束；普通清理留 TODO 或 Agent Note。
