## 1. 定位与变更规则

本文档把 README 中"尚未确认的实现决策"在 v1 范围内逐一给出归宿：**已决定**（D1–D11）、**延后**（试点验证中 / v2）或**保持开放**。决策依据全部指向 owning 设计文档，不引入新的语义设计。

变更规则：

- D1–D11 的任何变更必须更新本文件与实施计划，并重新获得用户确认；
- owning 设计文档变化时，本文件须同步校正，防止文档与决策漂移。

## 3. v1 执行边界与定稿偏差

1. 本次执行范围 M0–M4；试点与发布须用户重新发起。
2. 运行时门禁零脚本：只由记录模板必填字段 + 技能内检查清单 + git 审计承载；本仓库允许的脚本仅限安装器、身份生成器与构建期冒烟测试（编写规范 §2）。
3. 记录模板字段已定稿：门禁一 9 字段、门禁二 10 字段、门禁三 7 字段，落在 `preset/templates/workspace/memory/README.md` 与 `contract/current.md`。相对《Skill 编写规范》§7.2 候选枚举，定稿新增 `time_stability`，用于 1:1 承接门禁二"说明时间稳定性"这一必答要求；候选枚举中其余字段保持不变。

其余约束不在此重复：安装器边界、技能 frontmatter、人格分层预算、初始化确认与事实/解释更新语义，均以其 owning 设计文档为唯一权威。
