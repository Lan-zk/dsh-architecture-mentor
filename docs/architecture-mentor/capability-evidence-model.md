# 能力与证据模型

## 目的

Capability State（能力状态）不能根据“讲过什么”更新，只能根据学习者在具体上下文中的可观察表现更新。这个模型用于区分知识接触、局部表现、稳定判断和跨场景迁移，防止 AI 讲解或项目交付制造能力已经增长的假象。

导师可以自由选择怎样产生和验证这些表现，但任何能力状态提升都必须通过 [Capability State 提升门禁](./state-change-gates.md#门禁二提升-capability-state)。能力阶梯是证据描述工具，不是固定学习顺序。

## 能力阶梯

当前采用六个阶段描述证据所能支持的最高能力范围：

| 阶段 | 能证明什么 | 不能据此证明什么 |
| --- | --- | --- |
| Exposure（接触） | 看过、听过或参与过相关内容 | 能解释，更不能独立使用 |
| Explain（解释） | 能用自己的话解释概念、机制和基本权衡 | 能在真实系统中主动发现它 |
| Recognize（识别） | 能在给定系统中识别相关现象、约束或风险 | 能在开放问题中自主选择方案 |
| Decide（决策） | 能在具体约束下选择方案，并解释为何拒绝替代方案 | 能准确预测长期后果 |
| Predict（预测） | 能提前指出主要失败模式、成本和演进影响，并接受结果校准 | 能在约束变化后迁移判断 |
| Transfer（迁移） | 能在不同业务、规模或组织约束下重新判断，并知道结论为何可能反转 | 不代表所有相邻能力都已掌握 |

这些阶段不是课程进度，也不是人格评分。它们只表达“现有证据最多支持到哪里”。同一主题可以在不同子能力上处于不同阶段。

例如，对 Event-driven Architecture（事件驱动架构）的能力可能同时表现为：能解释基本原理，能在一个熟悉项目中识别它，但尚不能独立预测 Ordering（顺序）、Replay（重放）和 Backpressure（背压）问题。这时不能用一个笼统的“已掌握事件驱动架构”覆盖差异。

## 证据强度

能力阶梯描述行为深度，证据强度还需要考虑行为是否稳定和可迁移。

### Single-case Evidence（单案例证据）

说明学习者在这一次、这个上下文中做到了。它可以建立候选假设，但通常不足以形成稳定能力结论。

### Repeated Evidence（重复证据）

学习者在多个相似场景中重复表现出同一能力。它提高“能力已经稳定”的置信度，但仍可能只是熟悉同一类问题。

### Cross-context Evidence（跨场景证据）

学习者在业务、规模、可靠性要求、团队结构或技术条件不同的场景中重新完成判断，甚至得出与旧案例相反的结论。它是高置信度迁移能力的主要依据。

除了案例覆盖范围，还应记录以下因素：

- **独立性**：是在没有提示、轻微提示还是强引导下完成；
- **真实性**：是复述答案、封闭练习，还是真实或开放场景；
- **结果校准**：预测是否经过运行结果、历史事实或可靠反例验证；
- **时间稳定性**：是否在间隔一段时间后仍能重新做出判断；
- **反证情况**：是否存在与当前能力结论冲突的新表现。

具体权重和升级阈值仍待验证，不应仅凭累计次数机械升级。

## Hypothesis 与 Capability State 的区别

Hypothesis（导师假设）表达导师准备验证的诊断，例如：

> 学习者可能倾向于从解决方案开始，而不是先识别质量属性。

Capability State（能力状态）表达现有证据覆盖范围，例如：

```text
能力：异步架构判断
当前证据覆盖：Recognize（识别）

已证明：
- 能解释同步与异步的基本权衡；
- 能在给定场景中识别故障传播问题。

尚未证明：
- 能主动检查顺序和投递语义；
- 能在约束不同的项目中迁移判断。
```

“尚未证明”不等于“不会”。能力状态必须保留未知，不能为了得到整齐评分而把证据空白解释成能力缺失。

Capability State（能力状态）中的证据覆盖阶段，与记忆记录的 Lifecycle（生命周期）是两个维度。一个能力状态记录可以处于 `active`（活跃），但其证据只覆盖到 Recognize（识别）；`active` 只表示该记录当前值得影响教学，不表示能力已经掌握。

## 错误纠正是高价值证据

架构学习中，高价值变化往往不是“记住了一个模式”，而是心智模型被实际证据修正：

```text
原来认为 X
    ↓
发现 X 在条件 Y 下不成立
    ↓
识别真正关键变量 Z
    ↓
在新场景中据此改变判断
```

这类 Misconception Correction（错误认知纠正）应同时保留旧判断、触发修正的证据、新解释和后续迁移表现。它既能说明能力变化，也能帮助未来导师识别旧误区是否仍可能复发。

## 更新原则

- 一次成功产生 Evidence，不自动产生稳定 Capability。
- 能解释不等于能识别，能识别不等于能决策。
- 能在熟悉案例中做对，不等于能跨场景迁移。
- 新的反证可以让能力状态进入 Challenged（受质疑），而不是被忽略。
- 能力提升和退化都必须通过证据链更新，不能依赖印象。
- Capability State 是当前证据摘要，不是永久标签。
